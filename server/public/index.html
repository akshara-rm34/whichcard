WhichCard API

Backend for WhichCard, a location-aware credit-card rewards picker. Vercel Functions + Neon Postgres.

MethodPathAuthPurpose
GET/api/health—liveness check
POST/api/auth/signup—create an account
POST/api/auth/login—sign in, returns a token
GET/api/walletBearerthe signed-in user's cards
PUT/api/walletBearerreplace the wallet
GET/api/corrections?osmId=—community category for a merchant
POST/api/correctionsBearervote on a merchant's category
POST/api/eventsoptionalrecord a usage event
GET/api/events—aggregate counts only
Authenticate with Authorization: Bearer <token>. Full documentation in server/README.md.
